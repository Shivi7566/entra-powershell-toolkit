# Export-SecureScoreReport.ps1 - Explanation

## What this script does
Connects to the **Microsoft Graph Security API** to audit, retrieve, and export your Microsoft 365 / Entra ID tenant's live **Secure Score posture telemetry** into a structured CSV report. In a single execution, it:
1. **Verifies and installs the required `Microsoft.Graph.Security` PowerShell SDK module** under `-Scope CurrentUser` (no local admin rights needed).
2. **Authenticates securely to Microsoft Graph** with least-privilege scoped permissions (`SecurityEvents.Read.All`).
3. **Pulls the latest Secure Score snapshot**, calculating your tenant's current score, maximum potential score, and overall security percentage.
4. **Breaks down category score distributions** across Identity, Data, Devices, Apps, and Infrastructure.
5. **Retrieves all Improvement Action control profiles**, extracting metadata including implementation cost, user impact, tier, threats mitigated, and remediation impact.
6. **Exports the prioritized actions to a clean, timestamped CSV report** sorted by highest potential points gained.

---

## Prerequisites & Required Graph Scopes

To run this script, connect with an account holding **Security Reader**, **Global Reader**, or **Security Administrator** in your Microsoft 365 / Entra ID tenant.

The script requests the following least-privilege Microsoft Graph permission:
- `SecurityEvents.Read.All`: Read tenant security events, Secure Score snapshots, and improvement action control profiles.

## Step-by-step breakdown

### 1. Parameter Block & Output Path
The script accepts an optional `-OutputPath` parameter. If not provided, it defaults to a timestamped CSV file in the current working directory:
```powershell
.\Export-SecureScoreReport.ps1 -OutputPath "C:\Reports\SecureScore_Audit.csv"
```

### 2. Module Check & Auto-Installation
Checks if `Microsoft.Graph.Security` is installed on your workstation. If not found, it automatically installs it from the PowerShell Gallery (`PSGallery`) under the current user's scope.

### 3. Microsoft Graph Connection
Calls `Connect-MgGraph -Scopes "SecurityEvents.Read.All"` to initiate an interactive, modern OAuth 2.0 device or browser login. It verifies authentication context and prints the signed-in administrator account and Tenant ID.

### 4. Retrieving Latest Secure Score Snapshot
Uses `Get-MgSecuritySecureScore -Top 1` to retrieve the most recent daily posture snapshot generated by Microsoft Defender. Calculates:
$$\text{Posture \%} = \left( \frac{\text{Current Score}}{\text{Max Score}} \right) \times 100$$
Displays the overall score and snapshot timestamp in the console.

### 5. Category Point Breakdown
Loops through `$Latest.ControlScores` to display real-time points achieved across each posture category:
- **Identity** (Entra ID, MFA, SSPR, Legacy Auth, Privileged Access)
- **Devices** (Defender for Endpoint, Intune Compliance, BitLocker)
- **Apps** (Defender for Cloud Apps, OAuth consent, Shadow IT)
- **Data** (Purview Information Protection, DLP)

### 6. Improvement Action Retrieval & CSV Export
Queries `Get-MgSecuritySecureScoreControlProfile -All` to fetch all available improvement actions. Extracts:
- `Title`: Name of the security control.
- `Category`: Target security domain.
- `MaxPoints`: Maximum score points awarded upon 100% completion.
- `ActionType`: Configuration, Investigation, or Behavioral.
- `UserImpact`: Low, Moderate, or High impact on end-user friction.
- `ImplementationCost`: Low, Moderate, or High admin complexity.
- `Tier`: Core, Advanced, or Specialized.
- `ThreatsMitigated`: Specific attack vectors blocked (e.g., Credential Harvesting, Phishing).
- `RemediationImpact`: Detailed operational guidance.

Sorts the actions in descending order of **MaxPoints** and exports them directly to CSV using UTF-8 encoding.

## Usage Examples

### Basic Execution (Default Timestamped CSV)
```powershell
.\Export-SecureScoreReport.ps1
```

### Custom Output File Path
```powershell
.\Export-SecureScoreReport.ps1 -OutputPath ".\Executive_SecureScore_Q3.csv"
```
